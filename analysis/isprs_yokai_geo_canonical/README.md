# Canonical aggregate results

This directory records the single canonical analysis used by
`paper/foss4g-yokai-geo/main_submission_revised.tex`.

The repository-safe aggregate package contains:

- `results.json`
- `run_manifest_foss4g_final.json`
- `manuscript_qa_foss4g.json`
- `number_source_map.csv`
- `archive_language_associations.csv`
- `focal_associations.csv`
- dictionary-robustness summaries and replicates
- `threshold_sensitivity.csv`

The local working directory additionally contains record-level evidence,
municipality-level polygon derivatives, and qualitative source excerpts.
Those files are not intended for public redistribution until `TODO-AUTHOR`
confirms the Nichibunken, GADM, and W05 terms and the derived-data licence.
Their hashes remain recorded in the final manifest and inventory.

No human gold labels were created. Coverage values are not extraction
accuracy.
